# MERCY EMPIRE

A premium, responsive business website for **MERCY EMPIRE**, a beauty and fashion brand based in Port Harcourt, Nigeria.

## About

MERCY EMPIRE offers:

- Professional hairdressing
- Fashion designing
- Accessories
- Baby wear and essentials

The website showcases the brand's services, original work, selected fashion inspiration, and contact information.

## Features

- Responsive mobile-first design
- Premium beauty and fashion aesthetic
- Service showcase
- Filterable gallery
- Original-work labels
- WhatsApp enquiry buttons
- Google Maps directions
- Mobile navigation menu
- Smooth scroll animations
- SEO-friendly metadata

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
